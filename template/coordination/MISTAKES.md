# Граблі — помилка → корінь → правило

> Найцінніший файл пам'яті. Без нього ті самі помилки повторюються циклічно,
> бо симптом щоразу виглядає по-новому.
> Записуй КОРІНЬ, а не симптом: «тест не проходив» — це не запис.

Формат:

```
## YYYY-MM-DD — <симптом, як він виглядав>
**Що насправді сталося:** корінь.
**Чому не помітили одразу:** що збило з пантелику.
**Правило на майбутнє:** одне речення, яке треба виконувати.
```
