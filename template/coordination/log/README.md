# Журнал днів

Один файл на день: `YYYY-MM-DD.md`. Кожен чат наприкінці сесії дописує
3-7 рядків: що здано (з лінком на PR), що не закінчено, що передано далі,
які системні знахідки трапились дорогою.

Це не звіт для галочки: саме з цих рядків нічна автоматика робить вижимки,
і саме сюди дивиться наступна сесія, щоб зрозуміти, де все стоїть.

Чужі рядки не переписувати — тільки дописувати свої.
