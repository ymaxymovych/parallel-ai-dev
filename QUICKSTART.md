# QUICKSTART — від нуля до «✅ СИСТЕМА ГОТОВА»

> Найкоротший шлях. Розгорнуті пояснення — у `docs/01_STARTER_KIT.md`,
> навіщо це все — у `docs/00_JOB_DESCRIPTION.md`. Застряг — `docs/TROUBLESHOOTING.md`.

**Що потрібно:** git + термінал з bash (на Windows — Git Bash, він ставиться
разом із git; НЕ PowerShell). Перевір, що git знає, хто ти:
`git config user.email` — порожньо → `git config --global user.email "твій@email"`.

## 1. Постав комплект (один раз на комп'ютер)

```bash
git clone https://github.com/ymaxymovych/parallel-ai-dev.git ~/parallel-ai-dev
```

## 2. Розгорни пам'ять у СВОЄМУ проєкті

```bash
cd /шлях/до/твого/проєкту && bash ~/parallel-ai-dev/scripts/init-memory.sh
```

Скрипт нічого не перезаписує: наявні файли лишаються твоїми. Якщо в тебе вже
був `CLAUDE.md` — скрипт покаже один рядок, який треба в нього додати.

## 3. Заповни три декларації

Відкрий `coordination/SETUP.md` і заповни:

- `visibility:` — `private` чи `public-accepted` (глянь бейдж біля назви репо
  на GitHub; публічний = вся робоча пам'ять публікується назавжди).
- `mode:` — `team` (кілька чатів паралельно) чи `solo` (один чат).
- `constitution:` — лиши `kit`.

## 4. Подивись, чого бракує

```bash
bash ~/parallel-ai-dev/scripts/self-check.sh
```

Побачиш кілька червоних рядків R… — **це очікувано**: свіжа система і має бути
незаповненою. Список на екрані = твій чек-лист.

## 5. Закрий чек-лист

Зроби те, що каже КОЖЕН червоний рядок із кроку 4 — включно з комітом і пушем
(рядок R2 сам диктує команду). Орієнтири, куди підуть найважливіші 30 хвилин:

- `coordination/PROJECT_MAP.md` — що в проєкті ВЖЕ існує. Чесно і конкретно:
  без цієї карти чати будуватимуть уже збудоване.
- `coordination/DECISIONS.md` — 3-5 УЖЕ прийнятих рішень, кожне з полем
  «Чому» (включно з «ми свідомо НЕ робимо X»).
- `CLAUDE.md` — заповни `<...>`: ризикові зони, команда перевірки, команда деплою.

## 6. (mode: team) Створи друге робоче дерево

```bash
git worktree add ../$(basename "$PWD")-chat2 -b chat2
```

⚠️ Нове дерево — окрема тека: залежності (`node_modules` тощо) і файли `.env`
у нього НЕ переїжджають самі; про встановлення залежностей у дереві попроси
координатора (правило 3 конституції).

## 7. Фінальна перевірка

```bash
bash ~/parallel-ai-dev/scripts/self-check.sh
```

Має завершитись рядком `✅ СИСТЕМА ГОТОВА`. Не завершилась — кожен R-рядок
містить команду ремонту.

## 8. Жива перевірка (30 секунд, найпереконливіша)

Відкрий НОВИЙ чат Claude Code у проєкті промптом із `prompts/worker.md` і дай
йому задачу, яка в проєкті вже частково зроблена. Перший рядок відповіді має
бути вердиктом звірки («вже є отут…»), а не початком повторного будівництва.
Якщо так — система працює.
