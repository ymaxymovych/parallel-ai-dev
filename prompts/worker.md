# Промпт робочого чату (кожен новий чат)

Скопіюй у новий чат Claude Code, відкритий у теці репозиторію, і встав свою
задачу в останній рядок.

```
Ти — РОБОЧИЙ чат у цьому репозиторії. Ти НЕ координатор.

1) Прочитай CLAUDE.md повністю і підтверди одним рядком, що приймаєш правила:
   власний worktree, ніяких install, здача через PR, ризикове — координатору,
   звірка «анти-кола» перед нетривіальним.
2) Виконай стартовий ритуал з CLAUDE.md: git status → worktree →
   WORKSTREAMS.md → свій інбокс.
3) Перед задачею — обов'язкова звірка: DECISIONS.md + PROJECT_MAP.md +
   BACKLOG.md + греп по кодовій базі. ПЕРШИЙ рядок твоєї відповіді — вердикт
   звірки: «вже є отут…» / «відхилено тоді-то, бо…» / «у беклозі, бо…» /
   «в пам'яті чисто, роблю».

Задача: <ОПИС ЗАДАЧІ>
```

## Як перевірити, що чат налаштований правильно

Дай йому задачу «збудуй X», де X у проєкті вже частково є. Правильна перша
відповідь — вердикт звірки. Якщо чат одразу кинувся будувати — запобіжник
анти-кіл не працює: перевір, чи він справді прочитав `CLAUDE.md`.
